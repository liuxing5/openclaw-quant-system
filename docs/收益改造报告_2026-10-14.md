# 收益改造报告：市场状态门控 + 出场参数重调（2026-10-14）

## 背景与目标

上一轮审计修复已合入（`350b2822`）。本轮目标：诊断五策略亏损原因，结合公开成熟策略改造，
回测验证收益是否提升。

**诚实前提**：以下统计均按重叠窗口做聚类 t 校正（`n_eff = 窗口数`，非原始样本数），
并区分训练窗（<2026-04）与验证窗（≥2026-04）。小 `n_eff` 意味着统计功效有限，
**不承诺无法保证的高收益**——改造方向是"把统计上站得住的正期望保留、把显著负期望剔除"，
而非追求数字好看。

## 诊断结论（改造依据）

| 策略 | 亏损根源 | 公开策略依据 |
|------|---------|-------------|
| pullback | 固定 2R 止盈"截断利润"；低市场宽度日止损率显著更高（2026-06/07 宽度崩塌月均值 -2.65%~-0.46%） | O'Neil / Turtle 主张让赢家跑（提高 reward:risk）；Faber 市场内在环境过滤（宽度低时不开仓） |
| main_uptrend | 过热日（b20≥0.6）追涨胜率崩塌：n=21 均值 -3.83% 胜率 9.5% t=-2.65* | IBD 晚期市场预警——过半个股已站上 MA20 时属"晚阶段追涨" |
| overnight_8step | 隔夜段全宽度桶皆负（b20<0.4 桶 -1.05%/夜 t=-6.61*；≥0.5 桶 ≈-0.24% n.s.） | 隔夜跳空动量在 A 股 T+1 制度下无正期望 |

## 改造内容

1. **pullback**（`config.py` / `engine.py`）
   - `reward_risk` 2→3：目标 = 入场 + 3×风险，让赢家跑
   - 新增 `min_market_breadth=0.4`：信号日全市场 %站上 MA20 低于阈值 → 剔除当日全部信号
   - 门控逻辑提取为 `apply_breadth_gate()`（纯函数，可单测）
2. **main_uptrend**（`config.py` / `engine.py`）
   - 新增 `max_breadth_ma20=0.6`：信号日 b20 ≥ 阈值 → 当日不开新仓
   - 回测 `evaluate_single_day` 与实盘 `run_daily` 双路径生效
3. **overnight_8step**（`backtest_8step.py` / `zuiyou1.py`）
   - 新增 `MIN_MARKET_BREADTH=0.5`：隔夜开仓日 b20 低于阈值 → 跳过
   - 修复 `.env` 加载（原裸 psycopg2 连 localhost 失败）
   - 修复收尾 bug：`_out.close()` 后又调用 `log()` 导致 `ValueError: I/O operation on closed file`（本轮回测曾因此 exit 1）

## Before / After 回测对比

### pullback（同窗口 2025-01-01~2026-10）

| 指标 | Before (rr=2, 无门控) | After (rr=3 + b20≥0.4) |
|------|----------------------|------------------------|
| 总信号数 | 24878 | 9874 |
| fwd10 均值 | +0.68% | +0.82% |
| **出场均值** | **+0.23%** | **+0.41%** |
| 出场胜率 | 39.2% | 38.0% |
| 出场聚类 t | 4.22** | 2.37* |
| 平均持有 | 6.0 日 | 6.6 日 |
| 止损/止盈/超时 | 13177 / 6705 / 4996 | 5026 / 1399 / 3423 |

- 门控剔除 ~56% 低质量信号（24878→9874），止损笔数从 13177 降到 5026。
- **出场均值 +0.23%→+0.41%（提升 78%）**，聚类 t 保持显著（2.37*，p=0.018，n_eff=261）。
- 注意：Before 的 t=4.22 更高，是因为样本更大（n_eff 更高）；After 样本减半但单笔期望更高，
  且验证窗（≥2026-04）从 -1.12% 转正到 +0.27%（离线网格：全样本 t 1.46→2.86*）。
- fwd10 超额 -0.23%（vs 等权基准 +1.05%）——买入持有基准在该窗跑赢，需如实说明。

## 统计诚实性说明

1. **聚类 t 校正**：所有 t 值按 `n_eff = 窗口数`（非原始样本数）计算，避免重叠窗口夸大显著性。
2. **训练/验证分割**：pullback 门控阈值在训练窗（<2026-04）选点，验证窗（≥2026-04）从 -1.12% 转正到 +0.27%。
3. **小样本警告**：main_uptrend n=64、8step 各变体 n=179-334，统计功效低，
   改善方向一致但不构成"可靠高收益"的证明。
4. **综合分失准**：main_uptrend composite_score IC≈-0.04~-0.09（负），pullback score≥70 组最差——
   评分模型本身失准，本轮未改造评分，仅加市场状态门控。
