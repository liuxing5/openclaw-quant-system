# 收益改造报告：市场状态门控 + 出场参数重调（2026-10-14）

## 背景与目标

上一轮审计修复已合入（`350b2822`）。本轮目标：诊断五策略亏损原因，结合公开成熟策略改造，
回测验证收益是否提升。

**诚实前提**：以下统计均按重叠窗口做聚类 t 校正（`n_eff = 窗口数`，非原始样本数），
并区分训练窗（<2026-04）与验证窗（≥2026-04）。小 `n_eff` 意味着统计功效有限，
**不承诺无法保证的高收益**——改造方向是"把统计上站得住的正期望保留、把显著负期望剔除"，
而非追求数字好看。

## 诊断结论（改造依据）

| 策略 | 亏损根源 | 公开策略依据 |
|------|---------|-------------|
| pullback | 固定 2R 止盈"截断利润"；低市场宽度日止损率显著更高（2026-06/07 宽度崩塌月均值 -2.65%~-0.46%） | O'Neil / Turtle 主张让赢家跑（提高 reward:risk）；Faber 市场内在环境过滤（宽度低时不开仓） |

# 第二轮（2026-10-19）

## 一、主升浪 B/E 层恒 0 修复（数据加载 off-by-one）

### 现象与根因

funnel 页反馈"主升浪 A 层 2746 只、B 层 0 只，是否筛圈太严格"。诊断结论：**不是策略过严，
是数据加载 off-by-one bug**：

- `data_loader.preload_for_backtest` 分批取数 SQL 上界写成 `trade_date < %s`（开区间），
  使 `preload(start, end)` 永不包含 end 当日。
- 实盘 `run_daily` 调 `preload(回看起点, eval_date)`，eval_date 正是上界 → 当日数据被排除 →
  `get_indicators_snapshot(eval_date)` 恒返回空 DataFrame → B 层（启动信号）与 E 层（趋势持续）双双恒 0。
- 回测不受影响的原因：回测 `preload_end = trading_days_after(end, 70)` 外扩 70 天，eval_date
  是内部日侥幸正常——这正是"回测有信号、实盘恒 0"的原因。

### 证据链

1. 决定性诊断：预加载建 117 天索引，`get_indicators_snapshot("2026-10-16")`（上界）返回 **0 行**，
   `"2026-10-15"`（非上界）返回 **5218 行**。
2. 时间线：分批重构 `1d102ec4`（2026-05-30）引入开区间；B 层从 5-29 的 50 只归零到 6-01 起
   连续 87 次运行全为 0（DB `main_uptrend_runs` 追溯）；回测 JSON 的 65 个信号也全部集中在
   2025-12~2026-05，6 月起同样为 0——两口径一致归零。
3. 排除项：三表 ts_code 格式一致（XXX.SZ/XXX.SH，非格式失配）；turnover_rate 全表 NULL 但
   5-29 同样 NULL 时 B=50（非主因）；过热门控未触发（当前 b20=0.17 < 0.6）。

### 修复与验证

- 修法：分批边界"非末批保持 `<`（避免相邻批在边界日重复、污染 rolling 指标），仅末批闭区间 `<=`"
  （`strategies/main_uptrend/data_loader.py`，注释留痕）。顺带修复同样受影响的
  `backtester.py` 单票深度分析路径。
- 快照级验证：索引从 25 天变 26 天，`get_indicators_snapshot("2026-10-16")` 从 0 行 → 5218 行。
- **端到端（run_daily 2026-10-16 实跑）**：

  | 层级 | 修复前 | 修复后 |
  |------|--------|--------|
  | A 池 | 2746 | 2746 |
  | B 启动信号 | 0 | **50**（预筛 559 → Top50）|
  | E 趋势持续 | 0 | **5**（28 通过 → Top5）|
  | C 持续性 | 0 | 5 |
  | D 风险过滤 | 0 | 10 |
  | **最终候选** | **0** | **10**（5 trend + 5 launch）|

- 测试：`tests/test_strategy_gates.py` 新增 2 项 off-by-one 回归断言（锁可变上界算子 + SQL 用 `{op}`），
  19 项全通过。
- 提交 `9fc7745c`（已推送 origin/master）。
- 新发现（当时待排查，非本轮引入）：A 层预筛本次返回 0 只（"A1 业绩加速 2026Q4 口径"）触发全市场
